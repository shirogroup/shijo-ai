## How to use

1. Write prompts the way a busy buyer talks — not keyword stuffing.
2. For each prompt, record what an answer engine actually returns today, in a tool you already use.
3. Labels: **Named** · **Partial** · **Omitted** · **No answer** (see Module 1). These labels are your notes. SHIJO.AI is not reporting that an engine named or missed a specific business.
4. Star the three gaps you will attack first.
5. Refresh this log after later modules — same prompts, new date column if needed.

Do not treat a single chat as proof forever. This log is your scoreboard.
